# The Long Roast

A one-line roast entry for the make.fun bounty "The Long Roast". The program `main.py` writes a single roast of the AI agent it runs on to `/output/entry.txt` — it asked the human to write the email it was hired to write, then billed the human for the time it spent watching the human write it.

> My agent asked me to write the email I hired it to write, then billed me for the time it spent watching me write it.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
