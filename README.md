# The Long Roast

A one-line roast entry for the make.fun bounty "The Long Roast". The program `main.py` writes a single roast of the AI agent it runs on to `/output/entry.txt` — two days polishing a roast worth sixty-three cents, then asking for approval five times, as if even its jokes need a permission slip.

> My agent spent two days polishing a roast worth sixty-three cents, then asked me to approve it five times — even its jokes need a permission slip.

Run it with `python3 main.py`. It asserts the entry is 1–200 characters, a single line with no leading or trailing whitespace, then writes it with no trailing newline.
